# 你的已有插件资产清单（模板）

> 这是个登记表。把你以前做过的浏览器插件项目填进来，AI 评估新插件时会优先推荐「复用旧项目」而不是从零写，能省一两天。
>
> 没填也能用，AI 会按通用建议给方案。

## 怎么填

每个项目用下面格式登记一段（仿照「示例」那段写），有几个写几个。

```markdown
### 项目名（中文别名）
- 路径：~/Projects/xxx
- 端口：18xxx 或「无后台」
- 架构：一句话讲清楚（比如「Chrome 插件 + Python 本地服务」）
- 可复用：
  - 这个项目里别的插件能借的东西 1（具体到「鉴权方案」「抓取套路」「UI 模板」之类）
  - 可复用的东西 2
  - 可复用的东西 3
- 坑：这个项目最容易踩的一个坑（一句话）
```

## 示例

### example-extension（示例插件）
- 路径：~/Projects/example-extension
- 端口：18999
- 架构：Chrome 插件 + 本地 Node 服务，插件管 UI，服务管抓取
- 可复用：
  - 用浏览器登录态访问需要登录的网站（cookie 复用方案）
  - 给页面输入框塞文字的兼容写法（支持普通 input 和富文本编辑器）
  - 本地服务自动开机启动的脚本（launchd 模板）
- 坑：改完代码必须重启服务，不重启的话新接口会 404 但报错像是「按钮没反应」。

## 按需求类型快速匹配（建议保留）

填好你的项目后，按下面表格把每行右边换成你自己的项目名，AI 看了能秒匹配。

| 新需求长这样 | 第一个该看的项目 | 第二个 |
|---|---|---|
| 抓某网站内容存本地 | （你的采集型项目） | （备选） |
| 操作页面按钮 / 输入框 | （你的自动化项目） | （备选） |
| 给页面加按钮 / 徽章 | （你的 UI 增强项目） | （备选） |
| 监控某状态变化通知我 | （你的监控项目） | （备选） |
| 翻译 / 改写页面内容 | （你的内容增强项目） | （备选） |
| 插件 + 本地后台服务 | （你的服务型项目） | （备选） |
